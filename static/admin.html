Payment Gateway

Connect a payment provider so customers can pay online at checkout.

Gateway settings

How it works: the secret key is stored only on the server and is never sent to the website. When a provider is enabled, checkout shows it next to Cash on Delivery. Until you paste live keys and switch off test mode, gateway payments run in demo mode — the order is recorded as "Gateway (demo — not charged)" and no real money moves. Going fully live also needs the provider's hosted payment page/redirect to be wired with your merchant account — keep the keys here and that final hookup is a small step.
